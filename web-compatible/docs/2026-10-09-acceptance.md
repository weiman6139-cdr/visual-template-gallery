# 插件目标验收标准


> **状态：历史文档（已被取代）。** 本文件描述的是 MCP App 面板方案。本目录已改为纯网页端（浏览 + 复制模板名称），面板能力保留在上游项目。现行方案见 [2026-10-29 网页端方案](plans/2026-10-29-web-only-plan.json)；替代决策 ADR-0005 待补。

修订：2026-10-12。验收目标恢复为 Codex 插件内的完整模板浏览、手动选择和后续对话参考。旧 Web 测试、一次 Nopaper 生图和本地会话写入不能替代此目标。

## 结论规则

P0 主链路必须在真实 Codex 验证，全部通过才可标记项目完成。自动化、测试宿主和真实宿主分别记录，不相互替代。未验证项保持待验收，不能改为“不属于当前 MVP”而宣布完成。验收结果见[记录](2026-10-09-acceptance-result.md)。

## 需求到验收映射

| ID | 用户需求 / 等级 | 通过条件 | 必要证据 |
| --- | --- | --- | --- |
| P01 | 插件交付 / P0 | Codex 安装启用插件，加载其 MCP 工具和 ui:// 资源；默认不用 localhost 网页 | 插件状态、真实工具列表、宿主显示截图 |
| P02 | 调用对应 Skill / P0 | 请求目标 Skill 时，模型显式调用图库并传入正确路径 | Codex 工具调用记录；不能假称监听事件 |
| P03 | 全部模板 / P0 | 对照样例源索引，展示全部模板，默认无三个推荐限制 | 源索引总数、面板总数、跨页检查 |
| P04 | 官方示例 / P0 | 使用 GitHub 原图及缓存，失败明确且可重试，无预览生图 | 实际面板图片、来源、缓存/回退测试 |
| P05 | 直接手动选择 / P0 | 单选、跨页多选、移除、清空保持一致 | 真实面板操作及上下文对照 |
| P06 | 后续对话参考 / P0 | 点击选择后，宿主接收 update-model-context，用户无需复制；下一条任务可准确使用相同模板 | 宿主回执、用户发出的下一条任务、模型读取的 ID/来源/指导一致 |
| P07 | 失败真实性 / P0 | 无能力或拒绝时显示未同步，保留选择且可重试，禁止伪成功 | 禁用能力/模拟拒绝、实际错误与恢复 |
| P08 | 不固定生图 / P0 | 浏览与选择不调用图片模型/发消息；后续按用户任务使用宿主能力 | 工具调用记录、无 Provider 场景 |
| P09 | 降低接入格式要求 / P0 | 无 manifest 的样例，仅名称/ID+Markdown 标题或表格/HTML GitHub 图片可展示；模糊资料显示告警 | 对照夹具及真实样例 Skill |
| P10 | 隔离与回滚 / P0 | 已验证身份场景不同对话不可访问；重启会话失效；可卸载且不破坏源 Skill/其他插件 | 协议测试、真实宿主身份核查、回滚步骤 |

| P15 | MCP 无客户端重启刷新 / P1 | 在宿主暴露 app-server control socket 时，终端命令可发送官方 `config/mcpServer/reload`；没有 socket 时安全拒绝且不终止任何进程 | `npm run reload:mcp -- --socket PATH`、Unix socket 协议测试、当前桌面宿主边界记录 |
| P11 | 狭窄面板 / P1 | 面板完整可滚动，无横向遮挡，详情可关闭 | Codex 实际可用宽度和 320/440 测试宿主截图 |
| P12 | 右侧扩展面板 / P0 | 调用图库后在 Codex 右侧扩展面板展示，用户可同时在当前对话描述需求；对话内展示或全屏覆盖均不算通过 | 真实右侧面板截图及宿主显示状态；fullscreen 回执本身不代表通过 |
| P13 | 任务完成后消费 / P1 | 生图或其他任务完成后调用 `clear_template_context`，面板立即或经轮询取消选中并提交空 `content`；不追加清空说明注释 | 工具回执、面板状态、`ui/update-model-context` payload |
| P14 | 宿主拒绝处理 / P1 | MCP App 未挂载或宿主拒绝时，工具结果不伪造成功、不启动 localhost 网页；显示实际失败并允许宿主重载后重试 | 工具错误状态、无 TCP 监听、重载后的工具与资源检查 |

## 端到端步骤

1. 刷新插件后确认实际可调用 open_template_gallery；核对图库实际位于右侧扩展面板，不通过 open_in_codex 的 browser target 打开备用网页。仅有 inline 或 fullscreen 协议状态不代表右侧面板通过。
2. 请求 gpt-image-2-style-library 全库，对照当前本地索引数量，浏览两页和官方图。
3. 第 1 页选一个，第 2 页再选一个。核对已选列表与同步回执。
4. 用户直接发送“使用已选模板做……”或询问当前选择。模型应准确指出所选 ID，并结合参考执行任务，不要求用户复制；名称、ID、来源和指导应来自被动上下文。
5. 删除一项，再清空，分别验证后续参考撤销。同步失败后重试成功。
6. 切换目标 Skill、切换对话、重新打开视图，确认旧选择不意外复用；记录宿主是否提供 thread ID。
7. 在没有任何图片生成能力的环境中重复浏览选择；图库仍可正常工作，后续生图由宿主能力决定。

## 未验证的扩展需求

任意 Skill 调用事件监听、composer 上方原生可见注释以及其他 Agent 适配，仍需公开宿主能力核查。当前确认实现路径为显式模型调用 + MCP App + 被动模型参考；不将这三项冒充已实现。实际 MCP App 的位置由宿主控制；若不能进入右侧，P12 保持未通过，不能因此降低验收要求。

## 回滚验收

停用/卸载 visual-template-gallery@visual-template-local 后其他插件仍可用。旧 HTTP 服务和 Provider 已从当前项目删除；独立 Skill 原文仅作为历史资料保留。禁止修改应用安装文件、重置用户工作树或删除用户数据。
