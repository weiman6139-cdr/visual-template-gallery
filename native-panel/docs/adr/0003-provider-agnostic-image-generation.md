# ADR-0003: 生图能力不属于图库插件边界

## Status

Accepted

2026-10-16 补充：MCP App 主链路不导入 Provider Router，不在图库内生成图片。旧 HTTP Provider 实现已删除；后续对话任务使用宿主当时可用能力，参见 ADR-0004。

## Context

`sheng-tu` 是当前 Codex 本地环境的生图方式，但其他 Agent 或其他部署环境可能使用不同的模型、工具或 API。图库的职责是展示模板并提交参考上下文，不应持有模型凭证或运行图片生成代码。

## Decision

生图不属于图库插件边界。插件只提交模板参考上下文，后续任务由宿主当时可用的图片能力处理；`sheng-tu` 不作为插件依赖。

## Consequences

### Positive

- 插件不绑定 `sheng-tu`、Nopaper 或任何具体模型。
- 发行包不持有生图凭证，也不会因生图依赖缺失而无法浏览模板。
- 后续任务可以使用宿主当前提供的任意图片能力。

### Negative

- 当前尚未桥接 Codex 原生图片工具或其他 Agent 的运行时工具，需要宿主适配层。
- 图片工具的选择和结果消费由后续任务负责，图库无法监听任意外部生图完成事件。

## Alternatives Considered

- 在插件内置单一远程模型：部署简单，但引入账号、费用和供应商绑定，并偏离模板图库职责。
